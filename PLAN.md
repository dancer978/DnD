## Технический стек

**Выбор: Vanilla HTML + CSS + JS (ES modules)**

Аргументы:
- Нет билда → прямой деплой на GitHub Pages одной командой
- Нет зависимостей → никогда не сломается от обновления пакетов
- Логика квиза — это простой state machine, React здесь избыточен
- D&D-тема решается чистым CSS (шрифты, цвета, рамки)
- Весь контент в JSON — легко редактировать без программирования

## Архитектура данных (формат сценария)

Каждый сценарий — JS-файл с экспортом массива узлов:

```js
export const scenario = {
  character: {
    id: "recruiter",
    name: "Ловкий Рекрутер",
    role: "Специалист по найму",
    description: "Ты охотишься за талантами в мире, где каждый кандидат — на вес золота.",
    image: "recruiter_avatar.jpg"
  },
  nodes: {
    "start": {
      type: "scene",             // scene | ending
      title: "Квест начинается",
      text: "...",
      image: "scene_01.jpg",    // опционально
      choices: [
        { text: "Вариант А", next: "node_id_a" },
        { text: "Вариант Б", next: "node_id_b" }
      ]
    },
    "node_id_a": { ... },
    "ending_report": {
      type: "ending",
      title: "Ты нашёл путь",
      text: "...",
      service: {
        name: "Готовый отраслевой отчёт",
        price: "50–120 000 ₽",
        cta: "Получить отчёт",
        url: "#contact"
      }
    }
  }
}
```

Движок `engine.js` читает текущий узел по ID, рендерит, по клику переходит на `next`.

## Маппинг: персонаж → боли → услуги

### Ловкий Рекрутер
| Боль | Путь | Финал-услуга |
|------|------|--------------|
| Не знаю рыночные ставки | Ищет данные → получает аналитику | Готовый отчёт (50–120k) |
| Вакансия не закрывается месяцами | Ищет системный ответ | Экспертная сессия (250k) |
| Компания проигрывает конкурентам в найме | Нужна глубокая аналитика отрасли | Авторское исследование (400k+) |

### Волшебник HRD
| Боль | Путь | Финал-услуга |
|------|------|--------------|
| Текучка растёт, причины непонятны | Диагностика → стратегия | HR-стратегия (1.2M+) |
| Бюджет на HR режут, нечем обосновать | Нужны данные для защиты бюджета | Экспертная сессия / Отчёт |
| Нет системы мониторинга рынка | Хочет регулярный поток данных | Годовая программа (800k/год) |

### Лучник CEO
| Боль | Путь | Финал-услуга |
|------|------|--------------|
| Бизнес растёт, кадры тормозят рост | Нужна стратегия | HR-стратегия + Эдвайзеринг |
| Не понимает, что происходит на рынке труда | Нужен быстрый ввод в курс дела | Экспертная сессия (250k) |
| Конкуренты уводят людей | Нужен мониторинг + реакция | Годовая программа + Эдвайзеринг (1.2M+) |

### Гном-Собственник
| Боль | Путь | Финал-услуга |
|------|------|--------------|
| Нет HR-функции, нанимает сам — неэффективно | Хочет понять, как устроен рынок | Готовый отчёт (50–120k) |
| Кадровый бизнес, ищет данные для клиентов | B2B-логика | Авторское исследование (Кадровый бизнес, 400k+) |
| Хочет понять отрасль перед наймом | Быстрый ответ | Экспертная сессия (250k) |

### Директор по стратегии
Боли: несоответствие кадровой базы стратегическим планам, слепые пятна при выходе в новые рынки/регионы, нет данных для workforce planning.
Услуги: Авторское исследование, HR-стратегия, Годовая программа мониторинга.

### CFO (Финансовый директор)
Боли: HR-бюджет растёт, ROI непонятен; нет бенчмарков для обоснования ФОТ; риски при оптимизации — непредсказуемы.
Услуги: Экспертная сессия (быстрое обоснование), Авторское исследование (глубокий анализ), Готовый отчёт (бенчмарки).

### COO (Операционный директор)
Боли: производительность команд падает, ротация на ключевых позициях тормозит операции, дефицит редких специалистов под конкретные процессы.
Услуги: HR-стратегия, Годовая программа мониторинга, Авторское исследование.

### CCO (Коммерческий директор)
Боли: продажники уходят к конкурентам, рынок talent в коммерческих функциях перегрет, нет данных для формирования мотивационных пакетов.
Услуги: Экспертная сессия, Авторское исследование, Годовая программа + Эдвайзеринг.

## Глубина веток (на персонажа)

**Структура дерева:**
- 1 стартовый узел
- 3 первых выбора (три разные боли)
- Каждая ветка: 2–3 узла глубины
- Итого финалов на персонажа: 3 (каждый → своя услуга)
- Итого узлов на персонажа: ~10–12

**Всего узлов на 8 персонажей: ~80–96**

## Лид-магнит (в конце каждого пути)

После показа финала-услуги:
1. Поле: «Введи свою отрасль»
2. Ответ: 3 тренда рынка труда в этой отрасли (статичный или динамичный)
3. Форма: email или Telegram → «Сергей пришлёт материалы»

Форма отправки: простой `mailto:` или интеграция с Telegram Bot API (обсудить с Сергеем).

## Обогащение сценариев (следующий этап)

Сергей отметил, что в арсенале АРТ есть более широкий спектр инструментов аналитики, которые пока не отражены в ветках квиза. Нужно вплести их органично в истории — как развилки или как аргументы в финалах.

**Инструменты для интеграции:**
- **Демография** — изменения в структуре населения, старение рабочей силы, демографические ямы
- **Экономика** — макроэкономические тренды, влияние на ФОТ и доступность кандидатов
- **Миграция** — региональные и международные потоки трудовых ресурсов
- **Законодательство** — изменения в ТК, квоты, регуляторика найма

**Источники данных:**
- МСП (Министерство/платформа МСП)
- Хранилище `/opt/vault/` — документы АРТ

**Как интегрировать:**
- Добавить в отдельные ветки сцены, где персонаж сталкивается с демографическим или законодательным контекстом
- Использовать как усиление аргументации в финалах (почему проблема системная, а не случайная)
- Возможно: отдельные финалы, ведущие к исследованиям с демографическим/миграционным фокусом
